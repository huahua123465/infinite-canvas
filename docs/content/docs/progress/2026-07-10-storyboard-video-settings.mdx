## 需求目标

脚本节点提示词栏旁的视频设置应成为后续分镜视频的统一入口。用户不需要在整体提示词里重复编写分辨率、比例、时长、声音和水印；设置完成后，资产准备、合成提示词、待审核视频以及最终视频请求都应沿用这套配置。

分镜大弹窗不再重复显示整块视频设置，避免两个入口互相覆盖。完成“确认镜头 / 准备资产 / 合成提示词”后，脚本节点入口仍然可以继续修改。

## 最终行为规则

### 设置优先级

从高到低依次为：

1. 单个待审核视频中已经手动定制的设置。
2. 脚本节点提示词栏旁的视频设置入口。
3. 整体提示词或剧本文本中的“视频生成设置 / 视频设置 / video:”参数，仅在脚本节点对应字段为空时作为缺省兜底。
4. 全局视频默认配置。

提示词中的视频参数不得反向覆盖用户已经在界面中选择的脚本级设置。

### 自动同步范围

修改脚本节点的视频设置后，只同步满足以下条件的待审核视频：

- 属于当前脚本节点；
- 还没有生成视频结果；
- 没有被用户单独手动定制。

已生成视频、视频结果节点以及设置过 `storyboardVideoConfigCustomized` 的单镜头配置不应被批量覆盖。

### 时长模式

| 模式 | 脚本入口显示 | 单镜头行为 | 批量修改行为 |
| --- | --- | --- | --- |
| 按分镜 | 按分镜 | 从分镜表“时长”列读取当前行时长 | 每个未定制草稿恢复各自的逐镜时长 |
| 固定秒数 | 4s / 5s / 6s / 8s / 10s / 12s / 15s | 使用统一固定时长 | 覆盖全部未生成、未定制的待审核视频 |

分镜时长支持 `8`、`8s`、`8秒` 等写法，当前有效范围按视频设置限制为 4 至 15 秒。

内部值 `-1` 只表示“按分镜读取时长”，不得直接展示给用户，也不得作为实际视频秒数发送给生成接口。单镜头提示条、视频设置摘要、模型价格估算和实际生成请求都应使用当前分镜解析出的具体秒数，例如 `8s`。

如果处于“按分镜”模式但当前行没有解析到有效时长，生成应被阻止并提示“当前镜头没有读取到分镜时长，请先检查分镜表时长”，不得静默回退为默认 `6s`。

## 数据流

```text
脚本节点视频设置入口
  -> Script 节点 metadata（size / vquality / seconds / generateAudio / watermark）
  -> 同步未生成且未定制的待审核视频
  -> 最终提示词弹窗显示当前镜头具体设置和价格估算
  -> 生成前把“按分镜”解析为当前行实际秒数
  -> 视频生成请求
```

视频模型仍沿用当前全局视频模型选择；单镜头已经手动选择的模型继续由该镜头自己的定制配置保护。

## 本次修复的关键问题

### `8秒` 被错误回退为 `6s`

原逻辑优先依赖通用文本解析，纯中文单位写法没有稳定解析成功。现在先直接识别分镜表时长单元格中的 `数字 + 可选 s/秒`，再使用原解析逻辑兜底，因此 `8秒`、`10秒`、`12秒` 可以得到实际秒数。

### “按分镜”显示 `-1`

视频设置组件新增了可传入的“智能时长”显示文案。普通视频节点仍显示“智能”，脚本节点显示“按分镜”，单镜头最终提示词弹窗显示“按分镜 8s”一类的当前镜头实际结果。

当选择“按分镜”时，不再显示可编辑的 `-1` 数字输入框，改为说明当前时长来源。

### 设置修改后没有传到后续视频

脚本节点配置变化现在会同步到已有的合格待审核视频；创建或刷新待审核视频时也会重新读取脚本模板。生成前再次解析当前镜头时长，避免界面显示和实际请求不一致。
