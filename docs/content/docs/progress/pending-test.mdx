# 待测试

- Seedance 第三步合成提示词：合成 `storyboardPrompt` / `videoMotionPrompt` 时应更明确区分首帧静态画面和视频运动导演指令，并根据第二步资产清单收口 `assetMentions`，减少虚构资产、过度引用资产、运镜冲突和空泛堆词。
- 分镜视频节点：生成失败时应在节点主体区域清晰展示失败原因；放大节点后提示词、错误信息、参考资产和底部操作区的空间分配应更均衡。
- 脚本节点资产侧栏：视频或提示词相关动作结束/失败后，已选资产的“重新生成图片”按钮不应被无关状态置灰；仅资产生成中或批量资产动作中才应锁定。
- Seedance 最终提示词：当模型把 `@资产名` 和后续描述粘连在一起时，应优先按已有资产名前缀绑定参考图；后续合成提示词应要求资产名后用空格或标点隔开。
- 分镜视频多版本：待审核视频节点点击“生成视频”后应保留为可继续编辑的提示词节点，并在右侧新增独立视频结果节点；多次修改提示词生成时，旧视频和新视频应同时保留在画布中，下一镜首帧默认跟随上一镜最新成功版本。
- 分镜视频连续性：下一镜接入上一镜尾帧时，待审核节点和最终提示词弹窗都应明确显示首帧来源，例如“首帧来自第 1 镜 v1 尾帧”；未接入时应显示“未接入上一镜尾帧”。
- 分镜视频最终提示词弹窗：视频生成设置和最终提示词应自动保存到当前镜头，修改后显示“已自动保存”，关闭后再次打开仍保持上次设置。
- 分镜视频连续性编辑：编辑参考时应能从上一镜多个视频版本的尾帧中手动选择一个设为首帧，也能移除当前尾帧首帧；保存后最终提示词里的连续性要求同步更新。
- 分镜视频尾帧回填：打开已有项目时，旧的分镜视频结果如果还没有尾帧 metadata，应自动从视频中提取尾帧并出现在下一镜“连续性首帧”候选中。
- 分镜视频旧结果兼容：旧项目中已生成的视频即使缺少新版分镜结果字段，只要仍连接在上一镜待审核视频节点后，也应被识别为上一镜结果并参与尾帧回填和下一镜首帧候选。
- 分镜视频尾帧识别兜底：旧视频结果即使没有新版字段或连线，只要位于同一个视频工作区且位置靠近上一镜待审核视频节点，也应尝试归属上一镜、自动截取尾帧，并出现在下一镜“连续性首帧”候选中。
- 脚本节点画幅设置：脚本节点整体提示词中的“视频生成设置/比例”支持 `16:9`、`9:16`、`3:4`、`4:3`，后续资产图、分镜图、待审核视频节点和视频生成请求都应使用该比例；普通视频接口不应再把 `3:4` 近似成 `9:16` 或把 `4:3` 近似成 `16:9`。
- 脚本节点操作栏：大弹窗顶部第 3 步“合成提示词”旁应显示“批量合成提示词”按钮，底部不再重复放置该按钮，方便不滚动到底部也能批量合成。
- 配置与用户偏好：恢复方舟 Ark 调用格式选项，渠道调用格式应显示 OpenAI / Gemini / 方舟 Ark；选择方舟 Ark 时默认 Base URL 应为 `https://ark.cn-beijing.volces.com/api/v3`，模型列表支持填写 Seedance 模型 ID 或 Endpoint ID（`ep-xxxx`），且方舟 Endpoint ID 可进入视频模型可选项。
- 脚本节点视频设置：在脚本节点整体提示词中写入“视频生成设置/视频设置/video:”参数块时，应能解析分辨率、比例/尺寸、时长、生成声音和水印，自动同步到后续单镜头/批量视频草稿；已手动修改的待审核视频节点设置优先于脚本默认设置。
- Vite 融合迁移：新增 `custom/jt-vite-merge` 迁移分支，以官方 Vite + React Router 结构为底座迁入 custom/jt 的画布短剧工作流，需验证首页、画布项目页和基础文本/图片/配置/视频/音频节点仍可正常创建、连接、生成和重试。
- 脚本节点：迁入 Script Node、分镜大表格、TXT/MD/CSV/截图导入、连接剧本文本生成分镜、手动增删改镜头和 120 行上限，需重点验证三步流程“确认镜头 / 准备资产 / 合成提示词”以及第 9 列“分镜画面提示词”命名。
- 脚本节点：连接剧本文本生成分镜时，脚本节点自身的整体提示词会作为“整体要求/导演提示词”保留并传入后续流程，需验证第一人称 POV、皮克斯 3D 等自定义要求能贯穿确认镜头、准备资产、合成提示词和视频提示词。
- 分镜资产准备：迁入角色/场景/道具识别、阶段型进度条、精简分镜表请求、资产卡片编辑、上传资产图、单个/批量生成资产图和暂停生成，需验证不会把第 9 列提示词发送给资产识别。
- 角色资产风格：本次移除官方素材/虚拟演员 ID 绑定入口，角色资产统一按非写实虚拟角色、2.5D、动画或漫画质感生成；需验证第二步资产卡片、普通图片节点和第三步合成提示词中不再出现官方素材 ID 输入、官方脸标记或素材 URI 绑定提示。
- Seedance 视频提示词：迁入第三步 `storyboardPrompt` / `videoMotionPrompt` 双提示词、@ 资产引用解析高亮、最终视频提示词确认与可编辑入口，需验证单镜头和批量视频生成都优先使用 `videoMotionPrompt`，不退回第一步画面提示词。
- Seedance 视频审核：单镜头“生成视频”改为先创建待审核视频节点并打开最终提示词确认页；需验证普通视频和分镜视频参考图只使用已生成/上传的资产图、首帧和尾帧，不再插入官方素材引用。
- Seedance 提示词技能：恢复 `.agents/skills/seedance-video-prompting`，需确认 Codex 后续生成/审查 Seedance 视频提示词时能继续读取该 skill。
- 视频工作区与连续性：迁入待审核视频节点、参考资产编辑、首帧/参考/尾帧角色、非写实角色参考图提醒、视频阶段式进度条、成功后提取尾帧并传给下一镜首帧，需验证节点显示“已使用上一镜尾帧作为首帧”。
- Seedance REST 接口：保留 custom/jt 的官方接口修正，需用方舟环境验证 `POST /contents/generations/tasks`、`GET /contents/generations/tasks/{id}`、`content` 数组、`aspect_ratio`、`generate_audio`、大写 `480P/720P/1080P`、30 秒轮询、9 张参考图上限和 400 原始错误展示。
- Gemini 渠道：保留官方 v0.5.0 的 Gemini 调用格式、模型渠道配置和 Gemini 生图入口，需验证本次 Seedance/Script 迁移没有覆盖 `use-config-store`、image API 和模型选择器里的 Gemini 支持。
