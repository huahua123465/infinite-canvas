# 待测试

- 画布脚本节点 Seedance 提示词：新增项目本地 `seedance-video-prompting` skill，沉淀 Seedance 2.0 提示词指南中的主体绑定、分镜时序、动作细节、运镜、音频符号和约束规则；第三步“合成提示词”的系统提示词同步按 Seedance 2.0 导演指令补强，视频运动提示词会更强调起始状态、动作过程、结束状态、单一主运镜、身体细节、对白/音效和无字幕/无水印等稳定性约束。

- 画布角色卡照片导入：底部“导入角色卡”入口支持直接读取当前选中的人物照片，或选择本地图片后自动放入画布，并在照片旁创建一个生图配置节点；节点内预置方舟私域虚拟人像素材库所需的 6 张基准图提示词、2:3 尺寸和生成数量，用户只需点击节点里的“开始生成”即可批量生成正面全身、3/4 侧全身、侧面半身、近景胸像、表情动作和服装细节图。

- 画布脚本节点镜头编辑：第一步“确认镜头”里手动添加、编辑或删除镜头时，会基于最新分镜表连续更新，并保持在确认镜头视图，避免快速或连续添加时只生效一次；第一步和第三步底部支持导入外部分镜文本或 TXT/MD/CSV 文件，可识别 Markdown 表格、CSV/TSV、字段段落和普通逐行文本，并按镜号归位、追加或插入到指定镜头后；第三步“合成提示词”底部也可直接添加镜头并回到确认镜头编辑；长剧本生成、导入和节点预览的分镜行数上限放宽到 120 行，不再按 30 行截断。

- Codex 换线程交接模板：新增独立文档，提供旧对话总结提示词、新对话续接模板和极简可复制模板，用于减少长线程上下文膨胀与 token 成本。
- Codex App 插件文档：新增插件安装教程，区分 AI 自动安装、手动安装和本仓库开发调试安装；同步优化插件 README 与技能说明。
- 配置与用户偏好：每个模型渠道支持 OpenAI / Gemini / 方舟 Ark 调用格式选择，默认 OpenAI，切换默认格式时同步更新默认 Base URL；渠道 Tab 增加紧凑醒目的提醒，说明模型是否可选需要到“模型”Tab 选择。
- 方舟 Seedance 渠道：渠道配置新增“方舟 Ark”调用格式，支持直接填写方舟 Base URL、API Key，以及 Seedance 模型 ID 或 Endpoint ID（`ep-xxxx`）；选择方舟渠道的视频模型后会走 Seedance 视频任务接口，而不是误用 OpenAI 视频接口。
- 方舟 Seedance 视频接口：按官方“视频生成 API”对齐 `POST /contents/generations/tasks` 的 `content` 数组请求体，REST 请求使用 `aspect_ratio` 和大写 `480P/720P/1080P` 分辨率，分镜视频参考图上限按 Seedance 2.0 放宽到 9 张，任务轮询改为每 30 秒查询一次，并将真人参考图拦截、AI 仿真人参考图被识别为真人脸、非标准 Endpoint 请求体不匹配等常见英文错误转换为中文提示；任务创建 400 时会尽量展示方舟返回的原始错误字段，避免只看到 HTTP 状态码；已用 2.5D/非真人风格角色参考图跑通 6 秒视频生成链路。
- Gemini 调用格式：支持拉取 Gemini 模型列表，并用于文本问答、在线 Agent 工具调用、基础生图和图生图请求。
- 音频和视频生成：选择 Gemini 调用格式时先给出不支持提示；音频仍需使用 OpenAI 兼容渠道，视频可改用 OpenAI 兼容或方舟 Ark 渠道。
- 画布脚本节点：新增 Script 节点入口，可选择文本模型生成分镜脚本，节点卡片支持打开全屏分镜表格并编辑镜号、时长、画面、景别、对白、音效、运镜和最终提示词。
- 画布脚本节点第二期：脚本表格支持单行/批量合成最终提示词，并可按镜头生成分镜图或视频节点，生成结果自动连回脚本节点。
- 画布脚本节点资产准备：从分镜表进入“准备资产”后，可用文本模型识别全局风格、角色、场景和道具资产；资产页支持卡片预览、右侧编辑、上传资产图、单个生成资产图和一键生成所有资产图。
- 画布脚本节点合成提示词：第三步新增最终提示词弹窗，按单镜头保存分镜提示词、视频运动提示词和 @ 资产引用；分镜图生成优先使用分镜提示词，视频生成优先使用视频运动提示词。
- 画布脚本节点合成提示词视图：点击顶部第 3 步进入全表合成提示词视图，每个镜头可单独打开、重写、复制、生成分镜图或视频，也可批量重写全部镜头。
- 画布脚本节点合成提示词计数：第三步顶部、脚本节点卡片进度和“完成后可批量生视频”改为只统计已保存的合成结果，并按资产生成状态更新第二步完成态，不再把第一步表格里的“最终提示词”列误判为已完成。
- 画布脚本节点资产导出：脚本节点悬浮工具栏新增“批量生成资产”，可将第二步角色、场景、道具资产生成/导出为画布图片节点，并自动与脚本节点连线。
- 画布脚本节点视频生成：单镜头/批量生成视频时会使用第三步的视频运动提示词，并根据 @ 资产引用自动连接已导出的资产图片节点作为参考图。
- 画布脚本节点资产工作区：批量生成资产会创建可拖动的资产工作区背景板，资产节点放入工作区并随背景板整体移动。
- 画布脚本节点视频工作区：批量生成视频改为先搭建可拖动的视频工作区和待审核视频节点，写入视频提示词、资产引用和连线，审核后再单独生成视频。
- 画布脚本节点工作区布局：批量生成资产和批量生成视频连续触发时，资产工作区默认放在脚本节点右侧，视频工作区默认放在资产工作区右侧，视频待审核节点按每行 5 个排布，避免两组节点挤在一起。
- 画布脚本节点工作区删除：选中资产/视频工作区背景板点击删除或按 Delete 时，会同时删除工作区内子节点和相关连线，不再只删除背景板。
- 画布脚本节点工作区连线：工作区背景板只作为容器，不再显示连接点，也不再创建或渲染“工作区到子节点”的重复连线；子节点归属由工作区 metadata 维护。
- 画布工作区点击层级：资产/视频工作区背景板固定在子节点下方，工作区内图片和视频节点可优先点击，空白背景仍可用于选择和拖动工作区。
- 画布脚本节点资产 @ 绑定：第三步合成提示词会把 @ 人物、场景、道具校验并绑定到第二步导出的资产节点，提示词弹窗、合成列表和视频待审核节点会显示已绑定/未绑定状态；视频生成和视频工作区连线优先使用真实资产节点 ID。
- 画布脚本节点资产 @ 高亮：合成提示词弹窗新增 @ 资产高亮预览和本镜头引用资产列表，视频待审核节点会把正文里的 @ 资产渲染成明显标签，并在底部展示参考资产缩略图和已绑定/未绑定状态，方便确认视频模型参考资产是否正确。
- 画布脚本节点视频参考资产编辑：视频待审核节点可打开“编辑参考”弹窗，支持修改 @ 名称、删除参考图，并优先从当前剧本资产、兜底从“我的素材”图片中追加参考资产；弹窗会提醒方舟 Seedance 可能拒绝高度写实的 AI 仿真人参考图；参考图可标记为首帧、参考或尾帧，保存后该视频节点会优先使用自定义参考资产生成视频，并在生成提示词中补充首尾帧连续性要求。
- 画布脚本节点视频参考资产弹窗关闭：修复右上角关闭按钮无效的问题，并支持点击弹窗外部区域或按 Esc 关闭参考资产编辑弹窗；参考资产内部的首帧/参考/尾帧改为按钮组，避免选择角色、滚动或点击内部按钮时误关闭弹窗。
- 画布脚本节点视频提示词确认生成：视频待审核节点新增“查看提示词”入口，可查看原始视频运动提示词、参考资产顺序与角色、首尾帧连续性补充，以及实际用于视频生成的最终生成提示词；确认页内可选择视频模型和视频规格并直接点击“生成视频”，底部旧生成按钮会先打开该确认页，避免图二/图三提示词来源不一致。
- 画布脚本节点视频弹窗交互隔离：视频最终提示词确认页和参考资产编辑页改用自定义标题关闭按钮，并对整层 Modal 做画布事件隔离，避免点击关闭按钮无效，或在弹窗内部选择模型、切换首帧/参考/尾帧、删除/添加资产时被外层画布误判为关闭当前页面。
- 画布脚本节点视频底部面板：待审核视频节点不再显示选中后的底部通用提示词面板，统一通过节点卡片里的“查看提示词”进入最终提示词确认和视频生成，避免两个提示词入口混淆。
- 画布脚本节点视频最终提示词编辑：视频最终提示词确认页的最终生成提示词支持手动修改和 @ 资产输入，生成视频时优先使用人工编辑后的完整提示词；手动新增的 @ 资产会优先匹配当前剧本资产，再兜底匹配“我的素材”图片，并同步到参考资产列表一起传给视频模型。
- 画布脚本节点视频失败态：分镜视频节点在“生成中”或“生成失败”时，不再只显示通用转圈/报错面板；仍可直接查看提示词、编辑参考，并在卡片内看到方舟长轮询提示或错误详情，失败后也可原地重试。
- 画布脚本节点剧本输入：第一步“确认镜头”底部新增“从连接剧本生成镜头”入口，可读取连到脚本节点的文本节点内容并生成分镜表，同时保留原始剧本文本供资产准备和合成提示词使用。
- 画布脚本节点底部生成：选中脚本节点点击底部生成按钮时，会直接执行“从连接剧本生成镜头”的新流程，不再走旧版通用脚本 prompt。
- 画布脚本节点官方虚拟演员绑定：第二步“准备资产”识别角色后，会按角色性别、年龄、气质和剧本身份自动匹配官方虚拟演员候选；角色卡展示“官方脸”绑定状态，右侧编辑面板可切换候选演员并直接粘贴方舟控制台复制的 `asset-...`，系统会自动补成 `asset://asset-...`。第三步合成提示词会把官方脸视为角色演员底座；单镜头/批量视频生成时，如角色已填写合法官方素材 URI，会优先把该 `asset://` 作为 Seedance 第一参考图传入，本地或中转站生成的角色图只作为服装、体态和画风辅助参考；绑定官方素材后仍可生成可视角色预览图，生图提示词会自动补充官方脸基座说明；第二步单张或一键生成资产图时可点击“暂停生成”中止当前请求，已完成资产保留，未完成资产回到待生成状态。
- 画布普通图片节点官方素材：选中图片节点时，底部生成面板新增“官方素材”入口，空图片节点也可先填写；可自定义填写官方虚拟人像名称、`asset-...` / `asset://asset-...` 和标签说明。生成图片时会把官方脸基座说明补进提示词并把绑定关系保存到生成结果；当该图片作为 Seedance 视频节点参考图时，如已填写合法官方 Asset URI，会同时传入官方 `asset://` 和当前可视角色图，让官方脸负责审核基座，可视图负责服装、体态和画风参考。
