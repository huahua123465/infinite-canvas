# 视频生成任务恢复说明

视频生成由浏览器前端提交到模型平台。平台返回任务 ID 后会继续在服务端生成，浏览器只负责轮询状态和把最终视频保存回画布。因此，刷新页面会中断前端接收，但通常不会取消平台任务。

## 本次处理范围

- 视频节点当前选择的模型优先于上游配置节点和全局默认模型，避免界面选择 Seedance、实际日志却提交到其他模型。
- 视频节点展示实际提交模型和任务 ID，便于与平台任务日志核对。
- “查询原任务”只继续查询已有任务；“重新生成”确认后才清除旧任务信息并创建新任务。
- 服务繁忙自动等待 30 秒后重试一次；输入素材、内容策略、上游拒绝、超时和网络错误分别给出对应建议。
- 前台连续查询 5 分钟后转为低频后台查询，最长保留 30 分钟查询窗口，减少长任务被过早判定失败。
- 提交前在浏览器本地检查图片和视频参数。硬错误阻止提交，风险提示允许用户返回调整或仍然生成，不额外调用 AI 接口。
- 页面刷新后，有任务 ID、尚无视频结果的节点会自动恢复查询原任务；成功后写回原节点，不重新提交任务。

## 页面刷新后的恢复流程

1. 创建视频任务后，节点立即保存任务 ID、平台、实际模型、接口端点和提交时间。
2. 如果生成期间刷新页面，项目恢复时识别仍有任务 ID、但尚未保存视频内容的节点。
3. 前端按原任务记录恢复对应模型渠道，并继续查询原任务状态。
4. 平台任务成功后，前端下载或引用结果视频，保存到浏览器本地存储并更新原视频节点。
5. 分镜视频恢复成功后继续提取尾帧，并按原逻辑应用到下一镜连续性首帧。
6. 如果平台返回失败，节点展示真实平台错误；如果网络或查询再次中断，任务 ID 保留，可继续点击“查询原任务”。

自动恢复不会重新执行任务创建接口，因此不会因为一次页面刷新重复提交同一段视频。只有用户主动点击“重新生成”并确认后，系统才创建新任务。

## 无法自动恢复时

- 当前模型渠道的 Base URL 或 API Key 缺失时，先补全原任务使用的渠道配置，再点击“查询原任务”。
- 节点保留任务 ID 时，优先查询原任务，不要直接重新生成。
- 旧节点没有保存任务 ID 时，可在视频节点中手动填写平台任务 ID。
- 平台任务日志显示成功、但画布仍未接回时，核对节点显示的“实际提交模型”和任务 ID 是否与平台一致。
- 平台结果 URL 已过期或浏览器无法下载时，节点会保留原任务信息；可先在平台侧下载结果，再回到画布处理。

## 建议验收清单

- 选择视频节点模型后提交，平台日志中的模型与节点“实际提交模型”一致。
- 任务创建后能立即看到任务 ID。
- 生成中刷新页面，节点显示正在恢复原任务，不显示“请重新生成”。
- 平台任务在刷新期间完成后，画布自动接回视频并恢复成功状态。
- 分镜视频自动接回后仍能提取尾帧并传给下一镜。
- 刷新恢复过程没有出现第二条新建任务记录。
- 断网后恢复网络，可通过“查询原任务”继续查询同一个任务。
- 点击“重新生成”时会提示确认，并在确认后创建新的任务 ID。
- 低清晰度、近似纯色或画幅差异较大的参考图会先出现本地提示；损坏图片和不支持的参数会阻止提交。
