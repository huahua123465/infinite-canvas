# 官方 v0.8 合并记录

本文是官方 v0.8 合并工作的长期维护入口。后续继续合并时先阅读本文，再核对[待测试](/docs/progress/pending-test)和当前工作区，避免依赖聊天记录重复判断。

## 当前结论

- 第一阶段已经完成并由用户确认测试通过：官方 v0.8 的画布节点插件宿主核心已增量接入当前项目。
- 第二阶段代码已经完成，等待人工回归：SDK、模板、五个示例插件源码、浏览器 ESM、静态清单和固定依赖均已进入仓库。
- 2.5 阶段已经完成并由用户确认测试通过：官方左侧画布/素材导航已按当前 Script、Workspace、插件节点和本地素材结构增量接入，并支持折叠。
- 第三阶段代码已经完成，等待人工回归：模型脚本编辑器、OpenAI/Gemini 模板以及图片、文本、视频、音频执行入口已按独立提交接入。
- 根目录 `VERSION` 已切换为 `v0.8.0`，Vite 会把它注入画布右上角和版本弹窗；这只是当前融合分支的可见版本标识，不代表第三阶段已经通过测试或正式 tag 已发布。
- `@ant-design/pro-components` 在项目中只提供全局 `ProConfigProvider` 包裹，没有实际 Pro 组件消费者；现已移除该包裹及其 PrismJS 风险依赖链，保留现有 Ant Design `ConfigProvider`、主题 token 和根节点深色 class，依赖审计归零。
- 当前实现不会覆盖原有画布主文件，也没有把 Script、Workspace、Group 或生成链路迁入官方统一渲染器。
- 插件安装记录、缓存源码、启用状态和插件私有数据保存在当前浏览器的 IndexedDB/localforage，不会随 Git 提交同步给其他电脑或浏览器。
- 同事拉取代码后无需联网下载内置插件；管理器只读取仓库静态清单，第一次仍需在“内置可选”中点击“安装”，此时才执行对应插件代码。

## 同事拉取后的实际行为

| 内容 | 是否随 Git 拉取 | 说明 |
| --- | --- | --- |
| 插件管理弹窗与安全提示 | 是 | 拉取并启动前端后即可使用 |
| 动态节点注册、渲染、面板、工具栏和错误隔离 | 是 | 属于画布宿主运行时代码 |
| SDK、模板与五个示例插件源码 | 是 | 位于 `plugins/canvas/` |
| 五个内置浏览器 ESM 与固定依赖 | 是 | 位于 `web/public/plugins/`，未安装前不执行 |
| 内置插件静态清单 | 是 | 只读取 JSON 元信息，不导入插件模块 |
| 官方插件列表 | 否，运行时远程读取 | 默认从官方 `plugins-dist` 注册表获取 |
| 已安装/启用状态 | 否 | 每个浏览器独立保存 |
| 插件节点在画布中的 metadata | 随画布项目数据保存 | 但打开该节点的浏览器仍需安装并启用对应插件 |

同事第一次使用步骤：

1. 拉取 `custom/jt-vite-merge` 分支并按原方式启动 Web。
2. 打开任意画布，点击右上角“节点插件”。
3. 在“内置可选”中安装所需插件；该过程读取仓库静态文件，不依赖官方 CDN。
4. 关闭弹窗，通过双击画布空白处、连线创建菜单或底部工具栏创建插件节点。
5. 如果画布已有插件节点但当前浏览器未安装插件，节点会显示“缺少插件”；安装并启用同 ID 插件后恢复渲染，节点数据不会被删除。

## 当前仓库内置方式

- `web/public/plugins/catalog.json` 只保存插件名称、版本、说明、图标和相对 ESM 地址。
- 打开管理器只读取清单，不通过动态 import 执行插件。
- 用户点击“安装”后，宿主才从当前站点 `/plugins/` 目录直接加载 ESM，并将记录写入 localforage。
- 内置直载通道限制为当前站点 `/plugins/`；远程官方和第三方插件继续走源码下载、Blob 隔离和缓存路径。
- 内置插件未安装、未启用时不注册节点，不影响现有项目启动；安装后可继续禁用或卸载。

## 第一阶段已完成范围

### 插件管理与分发

- 支持官方插件注册表，并兼容清单中的相对 `entry` 和绝对 `url`。
- 支持第三方 HTTP/HTTPS 插件 URL 安装。
- 支持 `/plugins/index.json` 本地插件发现和 `VITE_DEV_PLUGINS` 开发插件加载。
- 支持安装、启用、禁用、来源更新和卸载。
- 更新时要求插件 ID 保持不变；新版本激活失败时尝试恢复旧版本。
- 管理器明确提示插件代码在当前页面执行，可以访问浏览器本地数据和 AI API Key，只应安装可信来源。

### 节点能力

- 插件节点类型使用独立动态注册表，不能覆盖内置节点，也不能与其他插件类型冲突。
- 双击创建菜单、连线创建菜单和底部工具栏可创建插件节点。
- 支持插件节点 Content、Panel、悬浮工具栏、双击处理、尺寸比例规则和连接点规则。
- 支持插件自定义小地图颜色。
- 插件节点可作为上游文本、图片、视频或音频资源。
- Canvas Agent 底层操作可以创建当前已注册的插件节点。

### 稳定性与数据

- 插件节点内容和面板使用错误边界，单个插件渲染失败不应让整张画布白屏。
- 插件工具栏、资源读取、双击行为、比例规则和清理函数分别隔离异常。
- 插件源码和安装状态使用 localforage 保存；插件私有存储按插件 ID 隔离。
- 禁用或卸载插件只移除运行时定义和样式，不删除已有画布节点。
- 缺少插件时显示占位提示；重新安装同 ID 插件后恢复渲染。
- 插件节点信息弹窗显示插件标题，未知或禁用类型显示原始类型 ID。

### 插件交互补丁

- 便利贴等带编辑按钮的插件支持双击正文进入编辑。
- 插件正文的非交互区域可以拖动节点，支持上下左右移动。
- 按钮、输入框、链接、iframe、canvas、可编辑区域和 `data-canvas-no-drag` 区域不会误触发节点拖动。
- 双击画布打开“选择节点”菜单后，点击菜单外任意区域即可关闭，右上角关闭按钮继续保留。

## 第二阶段已完成范围

- TypeScript SDK：公开类型、`definePlugin`、automatic JSX、宿主 React hooks 桥接和统一 esbuild 构建助手。
- 插件模板：独立 `package.json`、TypeScript 配置、构建入口、示例节点和开发说明。
- 便利贴：换色、编辑、衍生文本、双击正文和非交互区域拖动。
- HTML：无同源权限 sandbox iframe、CSP、上游 `{{input}}` 转义和内联脚本边界。
- Markdown：固定 `marked 17.0.6`，渲染前使用 `DOMPurify 3.4.12` HTML profile 净化。
- SVG：DOMPurify SVG profile，禁止脚本、`foreignObject`、`href` 和 `xlink:href`。
- 3D 全景：固定 `Three.js 0.180.0`，仓库同时包含入口模块依赖的 `three.core.js`，不依赖运行时 CDN，并清理动画、监听器、纹理和 WebGL 上下文。
- 仓库内置分发：静态清单、五个浏览器 ESM、固定依赖和许可证；默认未安装、未启用。

## 人工验证清单

### 安装与恢复

- “内置可选”列表能显示 Markdown、SVG、HTML、3D 全景和便利贴。
- 安装后节点类型立即出现在创建入口，无需刷新或重新安装。
- 禁用后已有节点显示“缺少插件”，重新启用后恢复内容。
- 更新失败时旧版本仍能恢复；卸载不会删除画布节点数据。

### 节点交互

- 便利贴正文双击后出现输入框，可以输入并保存文字。
- 从便利贴正文空白区域拖动时，节点能向任意方向移动。
- 点击换色、衍生文本、编辑按钮或输入框时不会移动节点。
- Markdown 可编辑和预览；SVG 可编辑源码或读取上游 SVG 文本。
- HTML 可在沙箱 iframe 中预览，并用 `{{input}}` 注入上游文本。
- 3D 全景连接等距柱状全景图片后可以拖拽旋转，不会移动节点本身。

### 原功能回归

- 创建和编辑内置文本、图片、视频、音频、配置、Script、Group 和 Workspace 节点。
- 打开 Script 三步工作流并执行一次资产、提示词或视频入口。
- 验证本地 Agent 和现有 Provider 配置仍可读取当前画布。
- 验证刷新、导入、导出和已有项目恢复不受插件节点类型放宽影响。

### 第三阶段：自定义模型调用脚本

状态：**代码已完成，等待人工回归**。

已合并：

- 设置页按媒体能力和渠道模型值编辑脚本，脚本使用独立 localforage 存储，不写入现有配置对象。
- 编辑器提供可用变量、返回约定、OpenAI/Gemini 模板和可信代码安全警告，并按需加载 CodeMirror JavaScript 支持。
- 图片脚本接入文生图、图生图和蒙版编辑；文本脚本接入现有文本问答入口，支持 `onDelta` 增量输出。
- 视频脚本自行完成请求和轮询并返回最终 URL 或 Blob；参考视频和参考音频会明确阻止，避免素材被静默丢弃。
- 音频脚本支持 URL、base64 或 Blob 返回值，参考音频通过 `params.referenceAudios` 提供；缓存键包含脚本内容，脚本模式不使用共享试听缓存。
- 每个入口只在脚本非空时分流；清空脚本立即恢复当前 OpenAI、Gemini、Ark、沧元、Seedance、火山或本地原生渠道。
- 在线 Agent 的工具调用保持原生协议，不经过用户脚本，避免改变现有工具循环。

安全边界：脚本在当前浏览器页面执行，能够读取对应渠道 API Key、访问任意网络并处理本地输入，只能粘贴和运行可信代码。当前 Vite、nginx、Docker 和 Vercel 配置未设置限制脚本联网的 CSP；第三阶段不把它包装成安全沙箱。
