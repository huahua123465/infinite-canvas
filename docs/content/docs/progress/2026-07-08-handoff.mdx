## 今天完成的主要事项

### 1. 新增沧元算力渠道格式

- 配置弹窗的渠道调用格式新增“沧元算力”。
- 默认 Base URL 为 `https://ai.cangyuansuanli.cn`。
- 保留原有 OpenAI / Gemini / 方舟 Ark 逻辑，不把沧元算力硬塞进 Ark Seedance 分支。
- 仍使用现有“拉取模型”按钮读取 `/v1/models`。

### 2. 模型能力分类补齐

- `omni` 会被归类为视频模型。
- `gemini-banana-*` 会被归类为图像模型。
- 原有 `seedance`、`sora`、`grok-video`、`flux`、`gpt-image` 等分类继续保留。

### 3. 图像生成适配

- 沧元算力图像渠道走 `POST /v1/images/generations`。
- 文生图和 JSON 图生图都走同一入口。
- 同步结果从 `data[].url` 读取。
- 异步结果会轮询 `GET /v1/images/generations/{task_id}`。
- 图生图参考图优先传 `image` / `images`，局部编辑传 `mask`。

### 4. 视频生成适配

- 沧元算力视频渠道走 `POST /v1/videos`。
- 轮询走 `GET /v1/videos/{task_id}`。
- 完成后优先读取 `video_url`，并兼容 `video.url`、`raw_data.video_url`、`data.video_url`、`data.url`；没有时再尝试 `/v1/videos/{task_id}/content`。
- 轮询间隔为 5 秒。
- 轮询响应会读取 `progress` 并用于节点真实百分比显示，失败时尽量展示 `error.message` / `error_code`。
- 参考视频或参考音频必须同时提供至少 1 张主参考图，符合沧元算力文档要求。
- 沧元算力下的 `seedance-2.0-*` 不再误走方舟 Ark 的 `/contents/generations/tasks`。

### 6. 模型价格显示

- 新增沧元算力价格读取服务，模型选择器会按渠道 Base URL 推导并缓存 `/api/pricing`，读取失败时保持原选择器逻辑不变。
- 沧元算力渠道的模型下拉项会在模型名后显示价格；`sora2` 会兼容价格数据源中的 `openai-sora2`。
- 视频工作台、画布配置节点、视频节点提示面板和最终提示词弹窗会把当前视频秒数传给模型选择器，按秒计费模型显示估算金额，按条/按次/按张计费模型显示单价。

### 7. 视频模型分辨率与参数分辨率联动

- 已识别 `seedance-2.0-1080p`、`seedance-2.0-720p`、`seedance-2.0-480p`、`seedance-2.0-4k` 等模型名里的固定分辨率档位。
- 在视频工作台、画布配置节点、视频节点提示面板和最终提示词弹窗里，选择带固定档位的模型会同步 `vquality`，设置按钮和面板显示也以模型档位为准。
- 在视频设置面板点击同系列可用档位时，会自动切换到对应模型，例如从 `seedance-2.0-1080p` 点 `720p` 会优先切到 `seedance-2.0-720p`，价格随模型刷新。
- 无固定分辨率档位的 Seedance 模型仍保留手动分辨率选择；生成请求兜底归一化仍以模型档位优先，避免旧节点残留参数造成冲突。
- 带参考视频/音频的沧元 Seedance 请求已固定把第一张参考图作为 `image_url` 主参考图发送，其余图片继续放入 `reference_images`，避免多图加参考视频时平台误判没有 reference image。
- 普通图片节点提示面板会显示本次“将传入参考图”和“已 @ 引用”的图片标签，便于确认连线图片和提示词中的 `图片1/图片2` 对应关系确实参与图生图请求。
- 画布视频生成会在任务创建后把 `videoTaskId`、平台、模型和端点保存到视频节点；生成中/失败状态显示任务 ID，点击“查询任务结果”会优先轮询已有任务并拉回平台已完成的视频，避免平台成功但画布一直转圈后只能重新扣费生成。旧视频节点没有保存任务 ID 时，可手动填写平台任务 ID 发起恢复查询。

### 8. 火山语音与角色试听缓存

- 修复火山 OpenSpeech TTS HTTP 返回解析：兼容二进制协议帧和逐行 JSON / base64 音频片段，避免接口成功但音频控件显示 `0:00 / 0:00`。
- 配置弹窗补充火山语音鉴权提示：新版豆包语音控制台填写语音专用 API Key；旧版 OpenSpeech 可填写 `APP ID|Access Token` 或包含 `appId` / `accessToken` 的 JSON，不需要 Secret Key。
- 角色声音编辑区的 speaker 输入改为可搜索、可粘贴的音色选择框，支持直接粘贴官方 `Voice_type`，并自动把复制出来的空格归一为下划线。
- 内置火山音色候选切换为官方 2.0 常用 `*_uranus_bigtts` 音色，包含知性灿灿、撒娇学妹、魅力女友、邻家女孩、温柔妈妈、少年梓辛、深夜播客、擎苍等，减少手填 ID 出错。
- 火山 2.0 `*_uranus_bigtts` 音色优先按 `seed-tts-2.0` 资源 ID 调用；旧版克隆类 speaker 仍按 `seed-icl-2.0` 处理；本地 Agent 代理和前端直连保持同一套推断逻辑。
- 音频生成新增缓存层：普通音频节点和脚本节点角色声音都会先查仓库共享试听缓存，再查浏览器 IndexedDB 本地缓存，最后才请求语音 API。
- 新增共享试听缓存目录 `web/public/audio/voice-previews/`，其中 `manifest.json` 用于登记团队共享试听音频，`README.md` 说明如何把精选样本加入仓库。
- 角色资产 metadata 记录 `voiceAudioCacheKey` 和 `voiceAudioCacheHit`，角色声音面板会显示“本地缓存 / 共享缓存”命中状态，并提供复制缓存 Key 入口，便于后续把满意的试听升级为仓库共享缓存。
- 试听缓存 key 会包含 Base URL、模型、音色、格式、语速、声音提示词和试听台词；同一配置重复生成不会再次扣费，不同角色或不同 speaker 不会误命中。
- 角色声音区新增“打开音色库”入口，弹窗内可搜索火山 2.0 音色，逐个点击“生成试听”听统一短文样本，再点击“选择”把 Voice_type 绑定给当前角色；该动作不立即生成角色正式台词音频。
- 音色库试听不是直接搬运火山控制台的官方免费试听文件；首次点击“生成试听”会用当前语音 API 生成样本，可能消耗额度，生成成功后才会进入本地缓存或后续共享缓存。

## 如果测试失败优先看

- 401 / 403：检查 API Key、账户权限和模型权限。
- 拉取模型为空：先直接验证 `GET https://ai.cangyuansuanli.cn/v1/models` 是否对当前 Key 开放。
- 图像无返回：检查响应里是否是异步任务 ID；如果是，应看轮询接口是否返回 `completed` 和 `data[].url`。
- 视频超时：确认任务状态是否停在 `queued` / `in_progress`，以及是否触发内容安全拦截。
- Seedance 相关参数错误：优先看是否传了不支持的比例、时长、参考视频/音频，或缺少主参考图。
- 火山 TTS 401 / 403：确认用的是豆包语音 / OpenSpeech 专用 API Key，不是方舟 API Key。
- 火山 TTS 资源不匹配：确认当前音频模型和 speaker 属于同一套资源；官方 2.0 `*_uranus_bigtts` 优先使用 `seed-tts-2.0`。
- 角色面板看不到缓存提示：确认前端服务已刷新到最新代码，并且当前打开的是脚本节点第二步的角色资产编辑面板。
- 3D 导演台关闭仍回首页：确认是从 `/canvas/:id` 进入或浏览器历史里上一页是当前画布；如果当前标签长期停留在旧 `/director-desk`，先刷新前端服务并重新从画布工具栏进入。
- 摄像机截图发送后画布没变化：确认当前画布项目已经加载完成，浏览器 IndexedDB / localforage 可写；旧无参数页面会兜底写入最近更新的画布，可先打开目标画布一次再重试。
