# 2026-07-13 分镜工作流交接

本文记录 `custom/jt-vite-merge` 分支本轮长篇纪实故事工作流改动。正式功能说明仍需人工测试确认后再更新。

## 当前制作口径

- 完整事实分镜与实际生产任务分开统计。当前示例保留 158 个事实分镜，但“标准纪实”只选择约 50 个动态视频镜头。
- 分镜拆细主要提升事实覆盖、单镜头动作清晰度和提示词可控性，不会单独保证视频连贯。
- 连贯性依赖同一角色时期资产、连续性组、章节、地点、光线、人物起止状态和相邻镜头站位。
- 只有同章节、同连续性组、前后均为动态镜头且转场为 `continue` 时，才允许接入上一镜尾帧。
- 跨年龄、时期、地点、章节或静态镜头间隔时主动断开尾帧，避免把错误外观和场景延续到下一段。

## 本轮完成

### 1. Script 专用生成入口与进度

- Script 节点外部闪电按钮和错误重试统一进入“自动生成完整分镜”流程，其他节点继续使用各自生成逻辑。
- 长任务显示事实提取、分批拆镜、遗漏补齐等阶段、百分比和进度条。
- 原文分段和镜头批次完成后保存检查点；停止或失败后保留断点，原文未变化时继续执行。

### 2. 制作模式与动态预算

- 新增“节省成本”“标准纪实”“完整细拍”“自定义”四种制作模式。
- 完整事实和 158 个分镜不因预算被删除，制作模式只决定哪些镜头进入动态视频生产。
- 动态预算默认约为 30 镜、50 镜、80% 镜或用户自定义数量。
- 切换制作模式在本地重新分配动态/静态镜头，不调用模型，也不覆盖已有视频。
- 批量视频工作区只创建 `renderMode=video` 且已有视频运动提示词的待审核节点。

### 3. 资产批量任务恢复

- 资产批量生成持久记录运行、中断、停止、完成状态以及成功/失败数量。
- 每张资产完成后立即保存；关闭再打开仍显示进度。
- 页面刷新无法恢复旧网络请求时，将遗留任务标记为中断，并允许继续生成剩余资产。
- 已有成功图片不会重复生成，部分失败不会误报全部成功。

### 4. 真人写实角色资产

- 移除强制“非写实虚拟角色、2.5D、动画或漫画、避免真人脸”的旧规则。
- 写实、真人、纪实项目锁定真实中国人物骨相、自然皮肤发丝、真实布料和纪实光影。
- 动画、漫画、3D、水墨等项目继续继承对应画风，不擅自改成真人。
- 资产编辑区分别显示可编辑原始提示词和实际提交给生图模型的完整提示词。

### 5. 角色身份设定图与参考图重做

- 角色资产默认生成横向 16:9 高分辨率身份设定图。
- 设定图包含正面主身份视图、全身正侧背、脸部多角度、表情、五官和发型细节。
- 主脸和主全身优先放大，避免面板太密导致视频模型无法识别人脸。
- 已有生成图或上传图后点击重新生成，会通过图像编辑接口真正上传当前图片，并把它作为最高优先级身份和画风参考。
- 重做失败时保留原图，不会先清空已认可资产。

### 6. 第三步只合成动态镜头

- 第三步顶部、底部、表格和 Script 画布节点统一显示动态镜头完成数，不再显示为 `0/158` 待生成视频。
- “批量合成”只调用尚无 `videoMotionPrompt` 的动态镜头，跳过静态事实镜头和已有结果。
- 批量任务支持暂停；每镜完成后立即保存，再次点击显示“继续合成剩余 N 个”。
- 静态事实镜头明确标记为不参与本轮批量合成，仍可按需单独合成。
- 合成阶段只调用文本模型生成首帧提示词、视频运动提示词和资产引用，不会自动调用图片或视频模型。

## 人工验证建议

1. 在标准纪实模式确认第三步显示约 50 个动态镜头，而不是 158 个视频任务。
2. 批量合成 2-3 镜后暂停，确认结果保留；再次点击只处理剩余镜头。
3. 抽查童年、青年、中年、晚年镜头，确认绑定了正确年龄状态的白秋妹资产。
4. 抽查同一连续性组动态镜头，确认尾帧只在允许条件下传递。
5. 抽查跨年龄、地点、章节和静态镜头间隔，确认没有错误继承上一镜尾帧。
6. 上传一张角色参考图后重新生成，确认身份和画风继承；失败时原图仍保留。

## 后续事项

- 当前自动分章可能把 158 镜拆成过多小章节，需要进一步收敛到约 8-12 个主要人生阶段。
- 静态事实镜头目前只保留在完整分镜中，尚未自动合并为 20-35 个可生产的静态蒙太奇段。
- 最终统一旁白、角色声音、环境音、音乐和静态/动态片段时间线合成仍需独立的成片阶段。
