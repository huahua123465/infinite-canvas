# 配置与用户偏好页签说明

配置与用户偏好弹窗用于管理模型渠道、默认模型、生成偏好、WebDAV 同步和本地 Codex 连接。它可以从右上角配置入口打开，也可以访问 `/config` 作为独立页面查看。

## 顶部页签

顶部的 `渠道`、`模型`、`生成偏好`、`WebDAV`、`Codex` 是同一套配置的不同分类。

### 渠道

`渠道` 用来保存可以调用的 AI 服务地址和密钥。一个渠道通常包含：

- 渠道名称：给自己看的名字，例如 OpenAI、Gemini、方舟、沧元算力。
- 调用格式：决定请求按哪种接口格式发送，当前包含 OpenAI、Gemini、方舟 Ark、沧元算力等格式。
- Base URL：模型服务的接口地址。
- API Key：该渠道的访问密钥。
- 模型列表：当前渠道可用的模型名，可以手动输入，也可以点击拉取模型。

新增或拉取模型后，还需要到 `模型` 页签把模型加入对应能力的可选项，否则画布节点的模型下拉里可能看不到它。

### 模型

`模型` 用来决定各类生成能力默认使用哪个模型，以及各处模型下拉框显示哪些候选模型。

它主要分两层：

- 可选项：文本、图片、视频、音频等能力分别允许出现哪些模型。
- 默认模型：新建节点、生成配置节点或工作台默认选中的模型。

如果同一个模型名来自不同渠道，界面会用渠道名辅助区分。切换这里的默认模型，会影响后续新建的生成节点；已经单独设置过模型的旧节点仍以节点自己的配置为准。

### 生成偏好

`生成偏好` 用来保存通用默认值，例如：

- 画布默认生图张数。
- 默认音频声音或火山 speaker。
- 默认音频格式。
- 默认音频语速。
- 默认音频指令。
- 系统提示词。

这些设置是全局默认偏好。单个节点或单次生成如果有自己的配置，会优先使用节点自己的设置。

### WebDAV

`WebDAV` 用来把浏览器本地保存的数据同步到你自己的 WebDAV 服务。它同步的是画布、我的素材、生成记录和本地媒体文件，不包含 AI API Key。

浏览器会直接连接 WebDAV 地址，不经过项目后端代理。因此 WebDAV 服务需要允许当前网页访问；如果遇到无法连接，常见原因是地址错误、账号密码错误、HTTPS 证书问题或服务端没有放开 CORS。

### Codex

`Codex` 用来把网页连接到本机运行的 `Canvas Agent`。连接成功后，Codex App 可以通过本机 Agent 读取当前画布、创建节点、修改节点、连接节点或触发生成。

这个页签只负责本地 Codex 连接配置。当前项目采用保守共存方案：右侧 Agent 面板里的 `网站 / 本机` 模式仍然保留，不会因为新增 Codex 页签而被删除。

## WebDAV 页签

截图中的 WebDAV 页面用于跨浏览器或跨设备备份与同步本地数据。

### WebDAV 地址

`WebDAV 地址` 是你的 WebDAV 服务入口，例如 NAS、坚果云、Nextcloud 或其他支持 WebDAV 的服务地址。

填写时需要填到 WebDAV 根路径或可写目录路径，例如：

```text
https://nas.example.com/webdav
```

### 远程目录

`远程目录` 是 Infinite Canvas 在 WebDAV 服务里使用的根文件夹。默认是：

```text
infinite-canvas
```

同步时会在这个目录下按业务分目录保存数据。每个目录里会包含 `manifest.json` 和 `files/`。当前主要分为：

- `canvas`：画布项目数据。
- `assets`：我的素材。
- `image-workbench`：生图工作台记录。
- `video-workbench`：视频创作台记录。

### 用户名

`用户名` 是 WebDAV 服务的登录账号。不同服务可能要求填写账号、邮箱或专门的 WebDAV 用户名。

### 密码 / 应用密码

`密码 / 应用密码` 是 WebDAV 登录凭证。很多云盘或 NAS 推荐使用应用密码，而不是账号主密码。

这个密码只用于浏览器连接 WebDAV，同步数据不会包含 AI API Key。

### 测试连接

`测试连接` 只检查 WebDAV 地址、远程目录和账号密码是否可用。测试成功说明浏览器可以访问远程目录。

如果按钮是灰色，通常是 WebDAV 地址还没填写完整，或正在同步中。

### 立即同步

`立即同步` 会开始同步画布、我的素材、生图工作台和视频创作台数据。同步过程中会显示各业务目录的进度。

它适合在换设备前、重要生成完成后或手动备份时使用。由于当前项目主要保存到浏览器本地，WebDAV 是跨设备同步和备份的主要方式。

### 尚未同步 / 上次同步

右上角状态显示当前 WebDAV 同步状态：

- `尚未同步`：当前浏览器还没有成功同步过。
- `上次同步 ...`：上一次成功同步的时间。
- 错误提示：连接、认证、路径、CORS 或网络异常时会显示失败原因。

## Codex 页签

截图中的 Codex 页面用于连接本机 Codex，不是配置在线模型渠道。

### 连接状态

右上角会显示当前连接状态：

- `未连接`：还没有开始连接本机 Agent。
- `连接中`：正在尝试连接。
- `已连接`：网页已经连上本机 Canvas Agent。
- `连接失败`：Local URL、Connect token、网页 Origin 绑定或本地服务状态有问题。

截图里显示 `连接失败`，说明当前网页没有成功连上 `http://127.0.0.1:17371` 对应的本机 Canvas Agent。

### 步骤 1：安装 Codex 插件

这里提示先在 Codex App 安装 Infinite Canvas 插件。插件的作用是注册 MCP 工具，并尝试启动本地 Canvas Agent。

安装后，你可以在 Codex App 里说打开 Infinite Canvas、读取画布、创建节点或触发生成。真正修改画布仍然通过本机 Canvas Agent 和浏览器画布之间的连接完成。

### 步骤 2：连接本地 Agent

这里提示在当前页填入 `Local URL` 和 `Connect token` 后点击连接。

连接成功后，网页会把当前画布快照同步给本机 Agent，Codex 调用 MCP 工具时就能读取这份画布状态。

### 步骤 3：手动启动备用

如果插件没有自动启动本地服务，可以在终端运行：

```bash
npx -y @basketikun/canvas-agent
```

启动输出里通常会包含本机地址和 Connect token。把它们填回 Codex 页签后再点击连接。

### Local URL

`Local URL` 是本机 Canvas Agent 的 HTTP 地址。默认常见值是：

```text
http://127.0.0.1:17371
```

这个地址只指向你自己电脑上的本地服务。网页通过它和 Canvas Agent 通信。

### Connect token

`Connect token` 是本机 Agent 输出的连接令牌。它用于确认当前网页有权限连接这个本机 Agent。

如果 token 填错、过期，或者 Agent 绑定的网页 Origin 和当前网页不一致，就会出现连接失败。

### 连接 / 取消连接 / 断开

按钮会根据当前状态变化：

- `连接`：开始连接本机 Agent。
- `取消连接`：正在连接时取消。
- `断开`：已经连接后断开本机 Agent。

连接失败时，可以先确认本机 Agent 是否正在运行，再检查 Local URL、Connect token 和当前网页地址是否匹配。

### 执行画布操作前确认

这个开关控制本地 Codex 执行画布写操作前是否需要你确认。

- 开启：Codex 想创建节点、修改节点、连接节点或触发生成时，网页会先展示待执行操作，确认后才应用到画布。
- 关闭：本地 Codex 可以直接执行画布工具调用，适合你已经信任当前会话、想减少确认步骤的时候。

这个开关只影响本地 Codex。右侧 `网站 Agent` 仍保留原有确认逻辑。

## 图一和图二的关系

图一是 `WebDAV` 页签，解决的是本地数据同步和备份问题。

图二是 `Codex` 页签，解决的是本机 Codex App 通过 Canvas Agent 操作画布的问题。

它们都在同一个配置弹窗里，但作用不同：

- WebDAV 面向数据同步。
- Codex 面向本机 Agent 连接和画布自动化操作。
- 渠道、模型、生成偏好面向 AI 模型调用和默认生成参数。
